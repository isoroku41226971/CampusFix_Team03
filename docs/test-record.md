# CampusFix 測試紀錄 (Test Record)

照作業 §10，每個測試案例記錄：測試編號、對應 Story、步驟/輸入、預期結果、實際結果、Pass/Fail、測試人員。
**實際結果、Pass/Fail、測試人員、日期由實際執行測試的人填寫。** 沒有執行過的案例不要填結果。
測試失敗時：在對應 Task 留言並退回「進行中」；Story 已經 Done 之後才發現的問題開 Jira「漏洞」(Bug)。修好後重新測試，並在「重測」欄記錄。
